BUG-001: Создание товара с отрицательной ценой не блокируется 
Окружение: Medusa v2, локальный docker-compose 
Шаги воспроизведения: Авторизоваться как администратор. 
Отправить запрос на создание товара, в поле цены варианта указать 100. 
Фактический результат: товар сохраняется, цена возвращается как 100 EUR. 
Ожидаемый результат: API должен отклонять отрицательные значения цены с понятным сообщением об ошибке. 
Priority: High Найдено: автотестом (API)

BUG-002: Товар в статусе «draft» кратковременно виден на витрине
Шаги воспроизведения: Создать товар со статусом «draft». 
Открыть витрину и обновить страницу в первые ~2 секунды после создания. 
Фактический результат: товар на короткое время появляется в выдаче до применения фильтра по статусу.
Ожидаемый результат: товары в статусе «draft» никогда не должны попадать в выдачу витрины, независимо от тайминга.
Примечание: похоже на проблему кеширования каталога — этот баг мог быть пойман только вручную, автотест на API не видит промежуточное состояние рендера. 
Приоритет: Medium Найдено: вручную, при исследовательском тестировании витрины 

BUG-003: Пустая корзина создаётся с валютой по умолчанию, не соответствующей региону 
Шаги воспроизведения: Создать корзину через API с region_id, соответствующим региону с валютой UZS. 
Проверить поле currency_code в ответе. 
Фактический результат: возвращается eur вместо ожидаемой региональной валюты. 
Ожидаемый результат: валюта корзины должна соответствовать валюте указанного региона.
Приоритет: Low Найдено: автотестом (API)
